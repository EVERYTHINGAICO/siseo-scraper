# Security and Support

This repository contains a standalone collector and dataset documentation. It requires no Supabase configuration or OAuth credentials.

Do not commit browser profiles, cookies, API keys, access tokens, client tracking lists, or diagnostic pages containing session state. Complete CAPTCHA prompts manually. This publication does not include historical browser profiles or local client lists.

Report ordinary issues with dependency versions, the command used, and redacted errors. Do not post secrets or private case information in public issues. For sensitive findings, arrange a private contact channel with the repository owner through [Everything AI Co](https://www.everythingaico.com/).

Collection selectors and external source behavior can change. No availability, completeness, support response time, or production service guarantee is made.
